Tài khoản gửi

Cửa sổ đăng nhập mở trong app. Đăng nhập xong thì đóng cửa sổ đó: app gửi sessionid và tt-target-idc lên backend, chỉ giữ trong RAM.

Dán cookie thủ công

Lấy ở DevTools, mục Application, Cookies của tiktok.com. App chuyển giá trị lên backend rồi xoá khỏi ô nhập.

Backend cục bộ

App tự khởi động backend trên máy này. Không cần nhập API key, token hoặc cài Node.js.
